## Team Roles and Responsibilities

### Product/Domain Lead
- Owns simulator roadmap and 3GPP fidelity targets
- Defines acceptance criteria and validates scenarios

### Technical Lead (Architecture)
- Owns module boundaries and platform performance
- Reviews cross-cutting changes and approves API contracts

### Runtime Owner
- Maintains core loop, FSMs, scheduling, and simulation state
- Ensures determinism and performance in hot paths

### UI/UX Owner
- Owns rendering, controls, layout, and accessibility
- Ensures good observability of simulation metrics

### QA/Tooling Owner
- Builds and maintains tests, CI, coverage, and release pipelines
- Enforces coding standards and contributor workflow
